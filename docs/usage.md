# 使い方・設定・検証

## レポートを読む・追加する

拡張一覧からxangi-reportを開き、「HTMLを追加」でファイルを選ぶかHTMLを貼り付け、タイトル等を確認して保存します。CSS・画像・必要なライブラリを埋め込んだ単一UTF-8 HTML（2 MiBまで）を使用します。JavaScriptは有効です。

PCでは左に一覧・右に本文を表示します。上部の「一覧」や一覧内の「一覧を閉じる」で開閉できます。境界をドラッグすると一覧幅を変更できます。境界にTabで移動し、左右キー（Shiftで大きく）、Home/Endでも変更でき、ダブルクリックで初期幅へ戻します。ドラッグ中のEscで取り消します。幅・開閉状態は同じブラウザで復元します。狭い画面では本文の幅を確保するため上限を調整します。

スマホは一覧と本文を一画面ずつ表示し、「一覧へ」や上部の「一覧」で往復します。PC用の幅設定は保持したまま、スマホには幅変更の境界を表示しません。

本文の「更新」で新版を保存します。旧版は自動削除せず、版選択から読めます。「HTMLを取得」は元のHTMLを返します。競合は上書きせず再読込を案内します。会話からの生成・登録には同梱スキルを使います。

大きい図や固定サイズのHTMLは、既定の「幅に合わせる」で横幅を収めて表示します。「表示倍率」の「全体表示」で縦横を一画面に収め、25〜200%で拡大・縮小できます。100%等で画面より大きくなる場合は本文領域を縦横にスクロールできます。倍率変更は原本や保存版を変えません。

検索欄の下の「絞り込み・並び順」を開くと、スター・表示対象・並び順・分類を変更できます。初期表示は折りたたみ、一覧に広さを確保します。絞り込み中やアーカイブ表示中は閉じた見出しにも状態を表示します。


## 並び順とアーカイブ

閲覧時はタイトル・倍率・「詳細・操作」・「表示を広げる」を1行に表示します。「詳細・操作」（⋯）を開くと、完全なタイトル・日時・取込元・分類、更新・スター・版選択・アーカイブ等を操作できます。「表示を広げる」は上部メニューと一覧を一時的に隠し、同じボタンで通常表示に戻せます。一覧の幅や開閉設定は変更しません。UIにフォーカスがあるときのEscでも詳細を閉じたり通常表示へ戻せます。

「並び順」は既定で更新が新しい順です。追加が新しい順、更新／追加が古い順、タイトル順へ切り替えられます。アーカイブしても更新日時は変えません。取り込みの「追加日」は取り込んだ日時です。

本文の「アーカイブ」で通常の一覧から外します。「表示」を「アーカイブ」にすると確認でき、本文の「アーカイブから戻す」で復元できます。「すべて」は両方を表示します。HTML・旧版・分類・スター・Notionの保存結果は残し、アーカイブのみではAI保存を実行しません。表示対象と並び順は同じブラウザで復元します。

## 過去のHTMLを取り込む

「HTMLを追加」内の「xangiの過去のHTMLから取り込む」でパスか、このxangiのプレビューURLを指定し「内容を確認」します。別workspaceはworkspace ID、添付は会話IDを指定できます（同時指定は不可）。内容確認後、タイトル・案件・カテゴリ・タグを整えて保存します。

元ファイルは編集せずコピーします。確認後に原本が変われば再確認を案内します。同じ出所・同じ内容は既存の取込版を開き、メタデータを上書きしません。同じ出所でも内容が異なれば別レポートとして保存します。ChatGPT等から持ち込むHTMLは通常のファイル選択で追加できます。

拡張は全履歴を自動走査しません。一括取り込みは対象を指定した別の作業です。相対画像・外部ライブラリの自動収集も行いません。

## カテゴリとタグ

追加時または「分類」で、カテゴリ1つ（60文字）・タグ20個まで（各40文字）を付けます。空のカテゴリは未分類です。分類だけでは本文の版を増やさず、Notion自動保存も実行しません。既存カテゴリは候補から選べます。分類の競合も検出します。

一覧でカテゴリ・タグ・スター・検索を組み合わせます。検索対象には分類名も含みます。フィルターは同じブラウザで復元し、「絞り込みを解除」で戻せます。カテゴリ階層や一括改名は初版にはありません。

## Notion保存

「Notion設定」で保存先・担当AI・スキルとタイミングを設定します。既定はoff。manualは表示中の版を明示保存、autoは以降の新規・更新時に保存します。過去分の一括送信はしません。offに戻しても依頼済みの会話やページは消しません。

接続は保存AIのNotionツールを使い、拡張にNotionキーを入力しません。利用者のworkspace/skills/NAME/SKILL.md、repo/skills-local/NAME/SKILL.md、同梱xangi-report-saveの順で方針を選びます。スキル名は英小文字・数字・ハイフンで64文字まで。同名の利用者版を優先します。

受付と保存完了は別です。完了・一部保存・回答待ち・失敗・結果不明を担当AIの報告に基づき表示します。完了には実ページURLと読み戻し照合の報告が必要です。拡張自身がNotionへ直接照合したことは意味しません。回答待ちは保存用会話で回答し、結果不明は会話とNotionを確認した後だけ再依頼します。

同じレポートの保存は直列化し、更新が重なると完了後に最新版を依頼します。古い版の完了を新版に転用しません。保存先変更時は以前の保存先のページを更新しません。NotionではJavaScriptは動かないため、読める本文と原本の添付・リンクを区別して未保存要素も記録します。Notionなしでもローカル保存・閲覧は使えます。

## 機能と設定

extension.config.jsonにID・表示名・版・ui/device/aiを保存し、configureがmanifestも生成します。uiとaiは独立して選べます（ui、ai、ui,ai、none）。deviceは未対応です。ui無効時は管理画面のrouteなし、ai無効時は保存設定を保持したまま実効保存モードoffで、新しいAI保存を行いません。取り込みのファイル取得はAI実行と独立しています。

```sh
npm run configure -- --features ui,ai
npm test
npm run build
```

設定・manifestの不一致はbuildで失敗します。名前やIDの変更は登録前を原則とし、既存データの移行なしにIDを変更しません。

- DATA_DIR: configureが表示するID別接頭辞を使用します。既定IDではXANGI_XANGI_DASH_REPORT_DATA_DIR。絶対パス、起動時適用です。
- 旧XANGI_REPORT_DATA_DIRも既定IDで互換対応。新旧が異なる値なら起動失敗として明示選択を求めます。
- XANGI_EXTENSION_AUTH_TOKEN: host注入、32文字以上のservice bearer。ブラウザ・ログへ出しません。
- XANGI_EXTENSION_HOST_URL: 親hostのorigin。別hostへ自動切替しません。
- XANGI_TOKEN: 親host API用。service tokenを流用しません。
- XANGI_EXTENSION_INSTANCE_ID: host注入。保存単位を決めるため確認なしに変えません。

担当AIは保存設定で選び、省略時はhostの既定を使用。別host・デバイス・環境変数による保存AIの切替はReportにはありません。保存方針の変更は次の依頼から適用し、送信済み処理を取り消しません。

## 保存先と復旧

既定はworkspace/.ID/INSTANCE_HASH/state.json。従来のxangi-reportはworkspace/.xangi-report/INSTANCE_HASHのままです。hashはinstance IDのSHA-256先頭16桁で、未指定時はdefaultをハッシュ化します。source内やsourceへ解決されるsymlinkは拒否します。

単一writerをlockで守り、逐次更新して一時ファイルからrenameします。破損時は空へ戻しません。停止中にバックアップし、保存先変更時は件数・ID・全版・設定・Notion対応を比較して移行します。単に保存先を変えることは移行ではありません。旧データは照合まで保持します。

データschemaは2。schema 1の原文をstate.schema-1.SHA256.jsonへコピーしてから移行し、既存情報を保持して分類を追加します。旧版へ戻す場合は停止し、移行後もバックアップしてからschema 1をstate.jsonへ復元します。manifestのschemaVersionとは別です。

EOF/SIGTERM/SIGINTで終了します。lock所有PIDが存在しなければ回収しますが、未完成lockやPID再利用は使用状況を調べて手動復旧します。同時の複数プロセスによるクラッシュ復旧は対象外です。queued/creating/sendingは再起動時にuncertainとして再送せず、requested/needs_inputは会話で確認します。

全版を保持し、自動削除・総容量制御は初版にはありません。容量と停止中バックアップを確認してください。更新・unlinkで保存データを削除しません。update.prepareはnpm ci/test/buildを実行します。

## 動作範囲と検証

sandboxは親DOM・Cookie/storage・通信・フォーム・別フレーム等を制限します。CDN、外部フォント、外部API、eval、相対資源に依存するHTMLはそのまま動かない場合があります。ダウンロード原本は書き換えません。Markdown/PDF、外部共有URLは未対応です。

npm testは設定・機能選択・HTTP・保存・移行・Notion状態を検査します。npm run buildは構文とmanifest一致です。既存環境にPython版Playwright/Chromiumがある場合は次を実行できます（製品依存には含めません）。

```sh
uv run --no-project python test/browser.py /absolute/path/to/artifacts
```

mockは実AI/Notionの検証ではありません。利用先でstatus/doctor・実画面・保存後の読み戻しと、本人端末の到達性を確認します。APIは[別資料](api.md)を参照してください。
